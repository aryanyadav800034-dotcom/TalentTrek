Getting Started

This quick guide helps you run and edit the Talentrek frontend locally.

How to open

  1. Double-click index.html to open in your browser (works offline).
  2. Or run the dev server (recommended): 
    npm install
npm start

Folder structure

/assets
  /css - styles (style.css)
  /js  - scripts (main.js, theme.js)
/index.html
/getting-started.html
/post-project.html
/project-details.html
/login.html
/dashboard.html

Notes

  • Theme persists between pages using localStorage.
  • All main buttons redirect to the proper pages (editable in assets/js/main.js).
  • Replace images in assets/images with your photos. (I left placeholder images.)
