
# Talentrek — Frontend (Local)
Simple, editable frontend bundle for Talentrek. Open `index.html` directly or run the small dev server.

## Run
- Double-click `index.html` to open in your default browser.
- Or (recommended) run the dev server:
```bash
npm install
npm start
```

## Structure
See /assets for css/js and /assets/images for placeholders.
